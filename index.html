Floyd–Warshall: Mở rộng khả năng truy vết đường đi ngắn nhất

1. Đặt vấn đề

Dijkstra là một cách quen thuộc để tìm đường ngắn nhất trên đồ thị có trọng số không âm. Chọn đỉnh 1 làm nguồn, ta tính được khoảng cách từ 1 đến các đỉnh còn lại. Nếu câu hỏi tiếp theo cũng xuất phát từ 1, ta chỉ việc tra lại kết quả. Nếu nguồn đổi sang 2, ta có thể phải chạy Dijkstra thêm một lần.

Khi cần trả lời cho nhiều cặp nguồn và đích, Floyd–Warshall tính trước khoảng cách giữa mọi cặp đỉnh bằng quy hoạch động. Kết quả nằm trong ma trận D. Đọc một ô, ta biết đường ngắn nhất dài bao nhiêu. Muốn in cả đường đi, ta có thể ghi thêm một dấu vết ngay lúc cập nhật ô đó.

Dấu vết ấy có thể là bước đầu tiên phải đi, hoặc là đỉnh trung gian nơi hai đoạn đường được ghép lại. Cả hai đều bắt đầu từ cùng một phép cập nhật của Floyd.

2. Floyd–Warshall cổ điển

Hàng i là đỉnh xuất phát, cột j là đỉnh đến. Ban đầu, D[i][i] = 0. Với hai đỉnh khác nhau, ta điền trọng số cạnh trực tiếp i → j nếu cạnh đó tồn tại, và điền ∞ nếu chưa có cạnh nối. Đồ thị có hướng nên hai ô đối xứng qua đường chéo có thể khác nhau.

Sau lượt k, các đỉnh từ 1 đến k đều có thể xuất hiện ở giữa đường đi. Khi xét thêm k, ta so sánh đường đang biết với đường ghép từ hai đoạn i ⇝ k và k ⇝ j.

D[i][j] = min(D[i][j], D[i][k] + D[k][j])

Hãy nhìn ô D[1][3]. Đi thẳng từ 1 tới 3 tốn 15. Ở lượt k = 2, đường 1 → 2 → 3 chỉ tốn 4 + 3 = 7, nên Floyd thay 15 bằng 7. Sang lượt k = 3, thuật toán đã có thể dùng số 7 ấy để tính đường từ 1 tới 4. Ghép thêm cạnh 3 → 4 có trọng số 2, ta được chi phí 9.

Ô D[1][4] giờ chứa số 9. Để in ra đường có chi phí 9 ấy, ta quay lại lúc Floyd chọn đi qua 3 và xem có thể ghi thêm điều gì.

3. Ghi bước kế tiếp bằng ma trận N

3.1. Từ một bước đi đến cả đường đi

Đứng ở đỉnh 1 và muốn tới đỉnh 4, ta chỉ cần biết nên đi sang đỉnh nào trước. Nếu câu trả lời là 2, ta đi sang 2 rồi hỏi tiếp cùng một câu với đích 4. Lặp lại cho tới khi chạm đích, các câu trả lời liên tiếp chính là đường cần in.

Ma trận Next-Hop lưu những câu trả lời đó. N[i][j] là đỉnh ngay sau i trên một đường ngắn nhất đang biết từ i đến j. Khi đường qua k được chọn, bước đầu nằm trên đoạn i ⇝ k, do đó N[i][j] = N[i][k].

Trong ví dụ, khi ghép đường 1 ⇝ 3 với cạnh 3 → 4, đỉnh trung gian là 3 nhưng bước đầu trên đường 1 ⇝ 3 là 2. Bởi vậy ta ghi N[1][4] = N[1][3] = 2.

3.2. Khởi tạo, cập nhật và truy vết trong Java

Trong mã dưới đây, d là D, next là N và nhãn đỉnh bắt đầu từ 1. Với cạnh trực tiếp u → v, bước đầu là v. Ô trên đường chéo giữ chính nhãn đỉnh, còn −1 đánh dấu cặp chưa có đường.

int[][] next = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(next[i], -1);
    next[i][i] = i;
    for (int j = 1; j <= n; j++) {
        if (i != j && d[i][j] != INF) next[i][j] = j;
    }
}

Đặt vòng lặp theo k ở ngoài cùng. Mỗi khi tổng của hai đoạn nhỏ hơn khoảng cách cũ, ta ghi cả chi phí mới lẫn bước đầu của đường mới.

for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        if (d[i][k] == INF) continue;
        for (int j = 1; j <= n; j++) {
            if (d[k][j] == INF) continue;
            long via = d[i][k] + d[k][j];
            if (via < d[i][j]) {
                d[i][j] = via;
                next[i][j] = next[i][k];
            }
        }
    }
}

Khi truy vết, giữ nguyên cột đích t và đổi hàng sau mỗi lần đọc. Với đích 4, các ô N[1][4], N[2][4], N[3][4] lần lượt trả về 2, 3, 4. Nếu từ s không tới được t, hàm trả về danh sách rỗng. Nếu s trùng t, danh sách chỉ chứa s. Trong tệp Java đầy đủ, distance(s, t) kiểm tra cả trường hợp chi phí giảm vô hạn do chu trình âm.

public List<Integer> nextPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    while (s != t) {
        s = next[s][t];
        path.add(s);
    }
    return path;
}

    4. Ghi đỉnh trung gian bằng ma trận M

    4.1. Nhớ chỗ ghép hai đoạn đường

    Cũng ở lần D[1][4] giảm xuống 9, ta có thể ghi lại chính đỉnh 3. Dấu này cho biết muốn dựng đường 1 ⇝ 4, hãy dựng đoạn 1 ⇝ 3 trước, rồi ghép với đoạn 3 ⇝ 4. Đến lượt đoạn 1 ⇝ 3, ta lại tìm được đỉnh 2 làm điểm chia.

    Đó là ý nghĩa của Intermediate Matrix. M[i][j] lưu đỉnh k ở lần cập nhật cuối làm giảm D[i][j]. Trên cùng một đường từ 1 tới 4, N lưu đỉnh 2 để ta bước tới, còn M lưu đỉnh 3 để ta tách đường thành hai phần.

    4.2. Khởi tạo, cập nhật và truy vết đệ quy trong Java

    Ban đầu các đường đã biết đều là cạnh trực tiếp hoặc đường từ một đỉnh tới chính nó. Mọi ô M vì thế được gán −1. Trong Java, ta đặt tên ma trận này là mid.

    int[][] mid = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(mid[i], -1);
}

    Ba vòng lặp tính khoảng cách vẫn như trước. Ở nhánh chấp nhận đường mới, phép gán cần thêm là mid[i][j] = k.

    long via = d[i][k] + d[k][j];
if (via < d[i][j]) {
    d[i][j] = via;
    mid[i][j] = k;
}

    Để dựng một đường hữu hạn, đưa đỉnh nguồn vào danh sách một lần. Nếu i = j, đoạn đã hoàn tất. Nếu mid[i][j] == -1 và i khác j, đoạn này là một cạnh trực tiếp, ta chỉ thêm j. Nếu ô chứa k, tiếp tục xử lý đoạn trái rồi đoạn phải. Chẳng hạn, sau khi đoạn 1 → 2 đã thêm đỉnh 2, đoạn 2 → 3 chỉ cần thêm đỉnh 3.

    public List<Integer> midPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    appendSegment(s, t, path);
    return path;
}

private void appendSegment(int i, int j, List<Integer> path) {
    if (i == j) return;
    int k = mid[i][j];
    if (k == -1) {
        path.add(j);
        return;
    }
    appendSegment(i, k, path);
    appendSegment(k, j, path);
}
