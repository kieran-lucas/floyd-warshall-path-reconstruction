Truy vết đường đi với Floyd–Warshall

1. Bài toán

Trên đồ thị có trọng số không âm, chạy Dijkstra từ đỉnh 1 cho ta khoảng cách từ 1 đến mọi đỉnh còn lại. Kết quả ấy dùng được cho cả hai câu hỏi 1 → 3 và 1 → 4. Nếu đổi nguồn sang đỉnh 2, ta có thể phải chạy lại Dijkstra.

Khi cần tra cứu giữa mọi cặp đỉnh, ta có thể dùng Floyd–Warshall để tính sẵn một bảng khoảng cách. Nếu đề bài còn yêu cầu in đường đi, ta cần biết mỗi khoảng cách trong bảng được tính từ những cạnh nào.

2. Ma trận khoảng cách của Floyd–Warshall

Gọi D là ma trận khoảng cách, với hàng là nguồn và cột là đích. Ban đầu mỗi ô mang trọng số của cạnh trực tiếp. Đường chéo bằng 0, còn ∞ nghĩa là hai đỉnh chưa có cạnh nối theo chiều đó.

Cạnh 1 → 3 có trọng số 15. Đi qua 2 chỉ tốn 4 + 3 = 7, nên Floyd đổi D[1][3] từ 15 thành 7. Cũng ở lượt này, đường 1 → 2 → 4 tốn 4 + 10 = 14, ngắn hơn cạnh trực tiếp có trọng số 20. Sang lượt xét đỉnh 3, ghép đường vừa tìm được từ 1 đến 3 với cạnh 3 → 4 chỉ tốn 7 + 2 = 9. Ô D[1][4] giảm từ 14 xuống 9.

Với mỗi đỉnh trung gian k, Floyd thực hiện cùng phép so sánh cho từng cặp i, j. Hai đoạn i → k và k → j có thể đã đi qua các đỉnh được xét ở những lượt trước.

D[i][j] = min(D[i][j], D[i][k] + D[k][j])

3. Các cách lưu vết cho Floyd–Warshall

Ô D[1][4] bây giờ chứa số 9. Để in đường đi, ta cần biết số 9 ấy ứng với dãy đỉnh nào. Hãy trở lại lúc Floyd ghép đường từ 1 tới 3 với cạnh 3 → 4. Ngay ở bước này, ta có thể ghi thêm thông tin để dùng khi truy vết.

Cách thứ nhất

Giả sử ta viết các đỉnh lần lượt từ nguồn đến đích. Viết 1 xong, ta cần biết đỉnh nào đứng ngay sau 1. Đường tới 4 bắt đầu bằng đoạn từ 1 tới 3, mà đoạn này đi qua 2 trước. Vậy đỉnh tiếp theo cần viết là 2. Đứng ở 2, ta lại cần biết phải đi sang đâu để tới 4.

Ta sẽ lập một ma trận bước kế tiếp, đặt tên là next, để có thể tra bước đi đầu tiên cho bất kỳ cặp đỉnh nào. Trên hình, ma trận này được ký hiệu là N. Với cạnh trực tiếp i → j, ban đầu ta ghi next[i][j] = j. Sau đó, mỗi khi Floyd tìm được đường ngắn hơn qua k, bước đầu của đường từ i tới j cũng là bước đầu của đoạn từ i tới k.

next[i][j] = next[i][k];
Khởi tạo N và cập nhật trong vòng lặp Floyd 
int[][] next = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(next[i], -1);
    next[i][i] = i;
    for (int j = 1; j <= n; j++) {
        if (i != j && d[i][j] != INF) next[i][j] = j;
    }
}
for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        if (d[i][k] == INF) continue;
        for (int j = 1; j <= n; j++) {
            if (d[k][j] == INF) continue;
            long via = d[i][k] + d[k][j];
            if (via < d[i][j]) {
                d[i][j] = via;
                next[i][j] = next[i][k];
            }
        }
    }
}

Khi truy vết, đích vẫn là 4. Đọc N[1][4] = 2 thì sang hàng 2, đọc N[2][4] = 3 thì sang hàng 3. Ô N[3][4] = 4 đưa ta tới đích.

public List<Integer> nextPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    while (s != t) {
        s = next[s][t];
        path.add(s);
    }
    return path;
}

Cách thứ hai

Ở phép ghép vừa rồi, Floyd dùng đỉnh 3 để nối hai đoạn đường. Nếu ghi lại số 3, sau này ta sẽ biết phải dựng đoạn 1 → 3 trước, rồi nối với đoạn 3 → 4. Áp dụng cùng ý tưởng cho đoạn 1 → 3, ta tìm lại được điểm chia là đỉnh 2.

Ta lập một ma trận đỉnh trung gian, đặt tên là mid và ký hiệu là M trên hình. Mỗi ô mid[i][j] lưu đỉnh k tại lần cập nhật gần nhất làm giảm D[i][j]. Ban đầu các ô đều bằng −1. Trong nhánh cập nhật khoảng cách, ta ghi thêm một dòng.

mid[i][j] = k;
Khởi tạo và cập nhật M trong Java 
int[][] mid = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(mid[i], -1);
}
long via = d[i][k] + d[k][j];
if (via < d[i][j]) {
    d[i][j] = via;
    mid[i][j] = k;
}

Hàm đệ quy dựng đoạn trái trước, đoạn phải sau. Khi i và j khác nhau, có đường đi và mid[i][j] == -1, đoạn còn lại là một cạnh. Chỉ cần thêm j vào danh sách vì i đã có ở cuối đường đang dựng. Nhờ vậy khi ghép 1 → 2 với 2 → 3, đỉnh 2 xuất hiện đúng một lần.

public List<Integer> midPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    appendSegment(s, t, path);
    return path;
}

private void appendSegment(int i, int j, List<Integer> path) {
    if (i == j) return;
    int k = mid[i][j];
    if (k == -1) {
        path.add(j);
        return;
    }
    appendSegment(i, k, path);
    appendSegment(k, j, path);
}
