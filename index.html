Truy vết đường đi với Floyd–Warshall

1. Bài toán

Dijkstra là thuật toán thường dùng để tìm đường đi ngắn nhất trên đồ thị có trọng số không âm. Chẳng hạn, chạy Dijkstra từ đỉnh 1 cho ta khoảng cách từ 1 đến các đỉnh còn lại. Kết quả ấy dùng được cho cả hai câu hỏi 1 → 3 và 1 → 4. Nhưng nếu đổi nguồn sang đỉnh 2, ta có thể phải chạy lại thuật toán.

Khi cần tìm đường đi giữa hai đỉnh bất kỳ, Floyd–Warshall cho phép tính trước khoảng cách ngắn nhất giữa mọi cặp đỉnh trong một lần chạy. Phiên bản cơ bản của thuật toán trả về ma trận khoảng cách; nếu muốn in ra dãy đỉnh của đường đi, ta cần khôi phục thông tin ấy. Ta sẽ tìm hiểu hai cách bổ sung ma trận lưu vết ngay trong quá trình tính Floyd.

2. Ma trận khoảng cách của Floyd–Warshall

Gọi D là ma trận khoảng cách, với hàng là nguồn và cột là đích. Ban đầu mỗi ô mang trọng số của cạnh trực tiếp. Đường chéo bằng 0, còn ∞ nghĩa là hai đỉnh chưa có cạnh nối theo chiều đó.

Cạnh 1 → 3 có trọng số 15. Đi qua 2 chỉ tốn 4 + 3 = 7, nên Floyd đổi D[1][3] từ 15 thành 7. Cũng ở lượt này, đường 1 → 2 → 4 tốn 4 + 10 = 14, ngắn hơn cạnh trực tiếp có trọng số 20. Sang lượt xét đỉnh 3, ghép đường vừa tìm được từ 1 đến 3 với cạnh 3 → 4 chỉ tốn 7 + 2 = 9. Ô D[1][4] giảm từ 14 xuống 9.

Sau lượt xét k, D[i][j] là khoảng cách ngắn nhất từ i đến j khi chỉ cho phép các đỉnh 1, 2, …, k làm trung gian. Hai đầu mút i, j không bị giới hạn trong tập này. Khi xét thêm k, ta so sánh đường đang có với đường ghép từ i đến k rồi từ k đến j. Hai đoạn này có thể đã đi qua các đỉnh trung gian được xét ở những lượt trước.

D[i][j] = min(D[i][j], D[i][k] + D[k][j])

3. Các cách lưu vết cho Floyd–Warshall

Sau khi chạy Floyd, D[1][4] = 9. Làm thế nào để từ kết quả đó khôi phục được đường đi 1 → 2 → 3 → 4? Hãy trở lại lúc Floyd ghép đường từ 1 tới 3 với cạnh 3 → 4. Ta có thể ghi nhớ bước đầu của đường mới, hoặc đỉnh trung gian vừa dùng để nối hai đoạn. Hai cách lưu thông tin này dẫn đến hai cách truy vết khác nhau.

Cách 1: Ma trận bước kế tiếp (Next-Hop Matrix)

Giả sử ta viết các đỉnh lần lượt từ nguồn đến đích. Viết 1 xong, ta cần biết đỉnh nào đứng ngay sau 1. Đường tới 4 bắt đầu bằng đoạn từ 1 tới 3, mà đoạn này đi qua 2 trước. Vậy đỉnh tiếp theo cần viết là 2. Đứng ở 2, ta lại cần biết phải đi sang đâu để tới 4.

Ta sẽ lập một ma trận bước kế tiếp, đặt tên là next, để có thể tra bước đi đầu tiên cho bất kỳ cặp đỉnh nào. Trên hình, ma trận này được ký hiệu là N. Với cạnh trực tiếp i → j, ban đầu ta ghi next[i][j] = j. Các ô chưa có đường đi được gán −1; trên đường chéo, next[i][i] = i. Sau đó, mỗi khi Floyd tìm được đường ngắn hơn qua k, bước đầu của đường từ i tới j cũng là bước đầu của đoạn từ i tới k.

int[][] next = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(next[i], -1);
    next[i][i] = i;
    for (int j = 1; j <= n; j++) {
        if (i != j && d[i][j] != INF) next[i][j] = j;
    }
}
for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        if (d[i][k] == INF) continue;
        for (int j = 1; j <= n; j++) {
            if (d[k][j] == INF) continue;
            long via = d[i][k] + d[k][j];
            if (via < d[i][j]) {
                d[i][j] = via;
                next[i][j] = next[i][k];
            }
        }
    }
}

Khi truy vết, đích vẫn là 4. Đọc N[1][4] = 2 thì sang hàng 2, đọc N[2][4] = 3 thì sang hàng 3. Ô N[3][4] = 4 đưa ta tới đích.

public List<Integer> nextPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    while (s != t) {
        s = next[s][t];
        path.add(s);
    }
    return path;
}

Trong hình dưới đây, chọn đỉnh 1 rồi đỉnh 4 để xem N được đọc theo cột 4. Chuyển sang giai đoạn xây dựng ma trận để theo dõi N thay đổi khi Floyd tìm được đường ngắn hơn.

Chương trình Java hoàn chỉnh — Next-Hop

Lưu vào tệp FloydWarshallNextHop.java hoặc Tải mã nguồn. Chương trình chỉ sử dụng ma trận D và ma trận N để truy vết một đường đi ngắn nhất.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public final class FloydWarshallNextHop {
    private static final long INF = Long.MAX_VALUE / 2;
    private final int n;
    private final long[][] d;
    private final int[][] next;

    public FloydWarshallNextHop(int n, int[][] edges) {
        this.n = n;
        d = new long[n + 1][n + 1];
        next = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            Arrays.fill(d[i], INF);
            Arrays.fill(next[i], -1);
            d[i][i] = 0;
            next[i][i] = i;
        }
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (w < d[u][v]) {
                d[u][v] = w;
                next[u][v] = v;
            }
        }
        build();
    }

    private void build() {
        for (int k = 1; k <= n; k++) {
            for (int i = 1; i <= n; i++) {
                if (d[i][k] == INF) continue;
                for (int j = 1; j <= n; j++) {
                    if (d[k][j] == INF) continue;
                    long via = d[i][k] + d[k][j];
                    if (via < d[i][j]) {
                        // Chặn tràn số khi một chu trình âm làm chi phí giảm liên tục.
                        d[i][j] = Math.max(-INF, via);
                        next[i][j] = next[i][k];
                    }
                }
            }
        }
    }

    public long distance(int s, int t) {
        for (int k = 1; k <= n; k++) {
            if (d[s][k] != INF && d[k][k] < 0 && d[k][t] != INF) {
                throw new IllegalStateException("Cặp đỉnh đi qua được chu trình âm.");
            }
        }
        return d[s][t];
    }

    public List<Integer> nextPath(int s, int t) {
        if (distance(s, t) == INF) return List.of();
        List<Integer> path = new ArrayList<>();
        path.add(s);
        while (s != t) {
            s = next[s][t];
            path.add(s);
        }
        return path;
    }

    public static void main(String[] args) {
        int[][] edges = {
            {1, 2, 4}, {1, 3, 15}, {1, 4, 20},
            {2, 3, 3}, {2, 4, 10}, {3, 4, 2}
        };
        int n = 4;
        if (args.length != 0 && args.length != 2) {
            throw new IllegalArgumentException("Dùng hai đối số: nguồn đích.");
        }
        int s = args.length == 0 ? 1 : Integer.parseInt(args[0]);
        int t = args.length == 0 ? 4 : Integer.parseInt(args[1]);
        if (s < 1 || s > n || t < 1 || t > n) {
            throw new IllegalArgumentException("Đỉnh phải thuộc khoảng 1.." + n);
        }
        FloydWarshallNextHop f = new FloydWarshallNextHop(n, edges);
        long length = f.distance(s, t);
        if (length == INF) {
            System.out.printf("Không có đường từ %d tới %d.%n", s, t);
            return;
        }
        System.out.printf("D[%d][%d] = %d%n", s, t, length);
        System.out.println("N = " + f.nextPath(s, t));
    }
}

Cách 2: Ma trận đỉnh trung gian (Intermediate Matrix)

Ở phép ghép vừa rồi, Floyd dùng đỉnh 3 để nối hai đoạn đường. Nếu ghi lại số 3, sau này ta sẽ biết phải dựng đoạn 1 → 3 trước, rồi nối với đoạn 3 → 4. Áp dụng cùng ý tưởng cho đoạn 1 → 3, ta tìm lại được điểm chia là đỉnh 2.

Ta lập một ma trận đỉnh trung gian, đặt tên là mid và ký hiệu là M trên hình. Mỗi ô mid[i][j] lưu đỉnh k tại lần cập nhật gần nhất làm giảm D[i][j]. Ban đầu các ô đều bằng −1.

int[][] mid = new int[n + 1][n + 1];
for (int i = 1; i <= n; i++) {
    Arrays.fill(mid[i], -1);
}

Khi đường qua k ngắn hơn, ta ghi k vào ô tương ứng.

long via = d[i][k] + d[k][j];
if (via < d[i][j]) {
    d[i][j] = via;
    mid[i][j] = k;
}

Hàm đệ quy dựng đoạn trái trước, đoạn phải sau. Khi i và j khác nhau, có đường đi và mid[i][j] == -1, đoạn còn lại là một cạnh. Chỉ cần thêm j vào danh sách vì i đã có ở cuối đường đang dựng. Nhờ vậy khi ghép 1 → 2 với 2 → 3, đỉnh 2 xuất hiện đúng một lần.

public List<Integer> midPath(int s, int t) {
    if (distance(s, t) == INF) return List.of();
    List<Integer> path = new ArrayList<>();
    path.add(s);
    appendSegment(s, t, path);
    return path;
}

private void appendSegment(int i, int j, List<Integer> path) {
    if (i == j) return;
    int k = mid[i][j];
    if (k == -1) {
        path.add(j);
        return;
    }
    appendSegment(i, k, path);
    appendSegment(k, j, path);
}

    Chương trình Java hoàn chỉnh — Intermediate

    Lưu vào tệp FloydWarshallIntermediate.java hoặc Tải mã nguồn. Chương trình chỉ sử dụng ma trận D và ma trận M để truy vết một đường đi ngắn nhất.

    import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public final class FloydWarshallIntermediate {
    private static final long INF = Long.MAX_VALUE / 2;
    private final int n;
    private final long[][] d;
    private final int[][] mid;

    public FloydWarshallIntermediate(int n, int[][] edges) {
        this.n = n;
        d = new long[n + 1][n + 1];
        mid = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            Arrays.fill(d[i], INF);
            Arrays.fill(mid[i], -1);
            d[i][i] = 0;
        }
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (w < d[u][v]) {
                d[u][v] = w;
            }
        }
        build();
    }

    private void build() {
        for (int k = 1; k <= n; k++) {
            for (int i = 1; i <= n; i++) {
                if (d[i][k] == INF) continue;
                for (int j = 1; j <= n; j++) {
                    if (d[k][j] == INF) continue;
                    long via = d[i][k] + d[k][j];
                    if (via < d[i][j]) {
                        // Chặn tràn số khi một chu trình âm làm chi phí giảm liên tục.
                        d[i][j] = Math.max(-INF, via);
                        mid[i][j] = k;
                    }
                }
            }
        }
    }

    public long distance(int s, int t) {
        for (int k = 1; k <= n; k++) {
            if (d[s][k] != INF && d[k][k] < 0 && d[k][t] != INF) {
                throw new IllegalStateException("Cặp đỉnh đi qua được chu trình âm.");
            }
        }
        return d[s][t];
    }

    public List<Integer> midPath(int s, int t) {
        if (distance(s, t) == INF) return List.of();
        List<Integer> path = new ArrayList<>();
        path.add(s);
        appendSegment(s, t, path);
        return path;
    }

    private void appendSegment(int i, int j, List<Integer> path) {
        if (i == j) return;
        int k = mid[i][j];
        if (k == -1) {
            path.add(j);
            return;
        }
        appendSegment(i, k, path);
        appendSegment(k, j, path);
    }

    public static void main(String[] args) {
        int[][] edges = {
            {1, 2, 4}, {1, 3, 15}, {1, 4, 20},
            {2, 3, 3}, {2, 4, 10}, {3, 4, 2}
        };
        int n = 4;
        if (args.length != 0 && args.length != 2) {
            throw new IllegalArgumentException("Dùng hai đối số: nguồn đích.");
        }
        int s = args.length == 0 ? 1 : Integer.parseInt(args[0]);
        int t = args.length == 0 ? 4 : Integer.parseInt(args[1]);
        if (s < 1 || s > n || t < 1 || t > n) {
            throw new IllegalArgumentException("Đỉnh phải thuộc khoảng 1.." + n);
        }
        FloydWarshallIntermediate f = new FloydWarshallIntermediate(n, edges);
        long length = f.distance(s, t);
        if (length == INF) {
            System.out.printf("Không có đường từ %d tới %d.%n", s, t);
            return;
        }
        System.out.printf("D[%d][%d] = %d%n", s, t, length);
        System.out.println("M = " + f.midPath(s, t));
    }
}

    5. Ưu và nhược điểm của hai phương pháp

    Hai phương pháp cùng mở rộng Floyd–Warshall bằng một ma trận lưu vết. Sự khác biệt chủ yếu nằm ở cách sử dụng ma trận sau khi đã tính xong khoảng cách. Gọi V là số đỉnh của đồ thị và L là số cạnh trên đường đi ngắn nhất được chọn.

    5.1. So sánh chi phí

    Tiêu chíNext-Hop (N)Intermediate (M)
    Thời gian tiền xử lýO(V³)O(V³)
    Bộ nhớ ma trận bổ sungΘ(V²)Θ(V²)
    Xác định bước đi đầu tiênΘ(1), đọc N[s][t]O(L), tìm cạnh đầu tiên bằng đệ quy
    Truy vết toàn bộ đường điΘ(L + 1)Θ(L + 1)
    Bộ nhớ phụ khi truy vếtΘ(1)O(L), do ngăn xếp đệ quy

    Chi phí trên xét cặp nguồn–đích đã được xác định có đường đi ngắn nhất hữu hạn, không tính bộ nhớ dành cho danh sách kết quả (Θ(L + 1) ở cả hai cách). Trong hai chương trình Java ở trên, hàm distance còn duyệt V đỉnh để kiểm tra chu trình âm, nên một truy vấn đầy đủ mất O(V + L + 1) thời gian.

    5.2. Sự khác biệt khi truy vết

    Next-Hop Matrix. Với mỗi cạnh của đường đi, thuật toán chỉ cần đọc một ô N và chuyển sang đỉnh tiếp theo. Một đường có L cạnh tương ứng với L lần tra ma trận. Cách này thuận tiện khi cần in các đỉnh theo thứ tự, xác định ngay bước đi tiếp theo hoặc thực hiện nhiều truy vấn. Đổi lại, N chỉ lưu bước đầu tiên của đường đã chọn; nó không trực tiếp biểu diễn các điểm chia được tạo ra trong quá trình Floyd–Warshall.

    Intermediate Matrix. M ghi lại chính đỉnh k dùng để ghép hai đoạn đường, nên cấu trúc lưu vết phản ánh trực tiếp phép truy hồi của Floyd–Warshall. Tuy nhiên, để dựng một đường có L ≥ 1 cạnh, hàm appendSegment thực hiện L − 1 lần phân chia và L lời gọi ứng với các cạnh trực tiếp, tổng cộng 2L − 1 lời gọi. Độ sâu đệ quy phụ thuộc vào cách các đoạn được chia; trong trường hợp xấu nhất, nó có thể tăng tuyến tính theo L. Vì vậy, dù độ phức tạp thời gian cùng bậc với Next-Hop, Intermediate có thêm chi phí gọi hàm và sử dụng ngăn xếp.

    Ví dụ, với đường 1 → 2 → 3 → 4 ở phần 4, Next-Hop đọc ba ô N, còn Intermediate đọc năm ô M: hai ô chứa điểm chia và ba ô ứng với cạnh trực tiếp. Đây là số bước của cơ chế truy vết, không phải kết quả đo thời gian chạy.

    5.3. Nên sử dụng phương pháp nào?

    Nếu mục tiêu là khôi phục đường đi để sử dụng trong chương trình, Next-Hop thường là lựa chọn thuận tiện hơn nhờ truy vết tuần tự và không cần đệ quy. Intermediate có giá trị khi muốn biểu diễn đường đi dưới dạng các bài toán con, đặc biệt trong việc minh họa tư tưởng quy hoạch động. Cả hai đều giữ nguyên bậc độ phức tạp của Floyd–Warshall và chỉ lưu một đường đi được chọn khi có nhiều đường ngắn nhất đồng hạng.
