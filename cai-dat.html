Cài đặt Floyd–Warshall bằng Java

Từ một phép so sánh khoảng cách, ghi ba loại dấu vết và kiểm tra xem cả ba có in ra cùng đường trong ví dụ hay không.

Chạy lại ví dụ bốn đỉnh

Chương trình lưu cả ba ma trận để đối chiếu trên cùng một lần chạy Floyd. Các đỉnh mang nhãn 1 đến 4 đúng như trên hình. Hai đối số là nguồn và đích. Khi bỏ qua cả hai, chương trình dùng cặp 1 → 4.

Tải FloydWarshallPaths.java ↓

Biên dịch và chạy

javac -encoding UTF-8 FloydWarshallPaths.java
java FloydWarshallPaths 1 4

Kết quả

D[1][4] = 5
N = [1, 2, 3, 4]
P = [1, 2, 3, 4]
M = [1, 2, 3, 4]

Đổi hai đối số thành 4 1 để thử cặp không có đường, hoặc 3 3 để nhận khoảng cách 0 và danh sách [3]. Lệnh java FloydWarshallPaths 2 4 cho đường [2, 3, 4] có tổng trọng số 3.

Mã nguồn đầy đủ

Bốn đoạn dưới đây ghép theo thứ tự thành đúng tệp tải về. Trong code, next, pred và mid tương ứng với N, P và M. Giá trị 0 trong ma trận truy vết biểu diễn ô chưa có dấu vì nhãn đỉnh bắt đầu từ 1.

Khai báo và khởi tạo

Chỉ điền dấu vết cho cạnh trực tiếp. Nếu có nhiều cạnh cùng chiều giữa hai đỉnh, giữ cạnh có trọng số nhỏ nhất.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.List;

public final class FloydWarshallPaths {
    private static final long INF = Long.MAX_VALUE / 2;
    private final int n;
    private final long[][] d;
    private final int[][] next, pred, mid;

    public FloydWarshallPaths(int n, int[][] edges) {
        this.n = n;
        d = new long[n + 1][n + 1];
        next = new int[n + 1][n + 1];
        pred = new int[n + 1][n + 1];
        mid = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            Arrays.fill(d[i], INF);
            d[i][i] = 0;
            next[i][i] = i;
        }
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (w < d[u][v]) {
                d[u][v] = w;
                next[u][v] = v;
                pred[u][v] = u;
            }
        }
        build();
    }

Chạy Floyd và kiểm tra cặp truy vấn

Hai lệnh continue bỏ qua các đoạn chưa tới được. Chỉ khi via nhỏ hơn giá trị cũ thì D và cả ba ma trận truy vết mới cùng cập nhật. Nếu nguồn tới được một chu trình âm rồi đi tiếp tới đích, có thể lặp chu trình để giảm chi phí tùy ý. Hàm distance báo trường hợp này trước khi truy vết.

    private void build() {
        for (int k = 1; k <= n; k++) {
            for (int i = 1; i <= n; i++) {
                if (d[i][k] == INF) continue;
                for (int j = 1; j <= n; j++) {
                    if (d[k][j] == INF) continue;
                    long via = d[i][k] + d[k][j];
                    if (via < d[i][j]) {
                        // Bound repeated decreases caused by negative cycles.
                        d[i][j] = Math.max(-INF, via);
                        next[i][j] = next[i][k];
                        pred[i][j] = pred[k][j];
                        mid[i][j] = k;
                    }
                }
            }
        }
    }

    public long distance(int s, int t) {
        for (int k = 1; k <= n; k++) {
            if (d[s][k] != INF && d[k][k] < 0 && d[k][t] != INF) {
                throw new IllegalStateException("Cặp đỉnh đi qua được chu trình âm.");
            }
        }
        return d[s][t];
    }

Dựng lại đường đi

Hai vòng while lần lượt đổi nguồn hiện tại hoặc đích hiện tại. Hàm đệ quy của M chỉ thêm đích của cạnh trực tiếp, nhờ đó mỗi đỉnh nối xuất hiện một lần.

    public List<Integer> nextPath(int s, int t) {
        if (distance(s, t) == INF) return List.of();
        List<Integer> path = new ArrayList<>();
        path.add(s);
        while (s != t) {
            s = next[s][t];
            path.add(s);
        }
        return path;
    }

    public List<Integer> predPath(int s, int t) {
        if (distance(s, t) == INF) return List.of();
        List<Integer> path = new ArrayList<>();
        path.add(t);
        while (t != s) {
            t = pred[s][t];
            path.add(t);
        }
        Collections.reverse(path);
        return path;
    }

    public List<Integer> midPath(int s, int t) {
        if (distance(s, t) == INF) return List.of();
        List<Integer> path = new ArrayList<>();
        path.add(s);
        appendSegment(s, t, path);
        return path;
    }

    private void appendSegment(int i, int j, List<Integer> path) {
        if (i == j) return;
        int k = mid[i][j];
        if (k == 0) {
            path.add(j);
            return;
        }
        appendSegment(i, k, path);
        appendSegment(k, j, path);
    }

Dữ liệu mẫu và điểm vào chương trình

Thay danh sách cạnh và số đỉnh để thử đồ thị khác. Mỗi bộ ba ghi đỉnh đầu, đỉnh cuối và trọng số nguyên của một cạnh có hướng.

    public static void main(String[] args) {
        int[][] edges = {
            {1, 2, 2}, {1, 3, 6}, {1, 4, 9},
            {2, 3, 1}, {2, 4, 6}, {3, 4, 2}
        };
        int n = 4;
        if (args.length != 0 && args.length != 2) {
            throw new IllegalArgumentException("Dùng hai đối số: nguồn đích.");
        }
        int s = args.length == 0 ? 1 : Integer.parseInt(args[0]);
        int t = args.length == 0 ? 4 : Integer.parseInt(args[1]);
        if (s < 1 || s > n || t < 1 || t > n) {
            throw new IllegalArgumentException("Đỉnh phải thuộc khoảng 1.." + n);
        }
        FloydWarshallPaths f = new FloydWarshallPaths(n, edges);
        long length = f.distance(s, t);
        if (length == INF) {
            System.out.printf("Không có đường từ %d tới %d.%n", s, t);
            return;
        }
        System.out.printf("D[%d][%d] = %d%n", s, t, length);
        System.out.println("N = " + f.nextPath(s, t));
        System.out.println("P = " + f.predPath(s, t));
        System.out.println("M = " + f.midPath(s, t));
    }
}

Với cặp có đường gồm L cạnh, phần dựng danh sách mất Θ(L + 1). Bản Java còn quét n đỉnh để kiểm tra chu trình âm cho mỗi truy vấn, nên tổng thời gian của một lời gọi truy vết là O(n + L).
